# 📦 Signum Mobile Wallet – Release Notes

The official, secure, and user-friendly wallet for the Signum blockchain ecosystem.  
Send, receive, and manage **Signa and Tokens** effortlessly — anytime, anywhere.

---

### 🧭 iOS

**App Store Name:** Signum Mobile Wallet  
**Subtitle:** Send & Receive Signa  
**Category:** Finance  
**Supported Languages:** English, Spanish, Portuguese, French, German, Chinese, Russian  
**Version:** 1.2.0

#### 🚀 New in This Version
- Added support for **Signa and Token transfers**  
- **Automatic Logout / Inactivity Protection** — the wallet now automatically locks after a period of inactivity for improved security  
- **Manage miner commitment** – easily add or remove your mining commitment remotely  
- **Multi-language interface** – available in 🇬🇧 English, 🇪🇸 Spanish, 🇵🇹 Portuguese, 🇫🇷 French, 🇩🇪 German, 🇨🇳 Chinese, and 🇷🇺 Russian  
- **Fiat currency display** for balances and token values  
- Improved **QR code features**:  
  - Import accounts (address or recovery phrase)  
  - Pay with Signa  
  - Create payment requests via QR code  
- **Enhanced security**:  
  - PIN and fingerprint authentication  
  - Local transaction signing – private keys never leave your device  
- **UI/UX improvements** for a smoother and more intuitive experience  
- **Custom or predefined node selection**  
- **Detailed transaction view** with P2P message decryption  

#### 🔒 Security
- Private keys are encrypted and stored locally  
- Recovery phrases are **never stored** on the device  
- All transactions are **signed locally** for maximum privacy  
- **Automatic inactivity logout** – protects your wallet if left unattended  

#### 🌍 General
- Open Source  
- Fully decentralized and community-driven  
- Built for the Signum ecosystem  
- ⚡ **Note:** This is *not* a mining app.  
  It allows you to manage the **commitment of your existing miner** only — mining itself must be done on your computer or node.

### 🟢 Android

**App Name:** Signum Mobile Wallet  
**Short Description:** The fastest and most secure way to manage Signa and Tokens.  
**Category:** Finance  
**Supported Languages:** English, Spanish, Portuguese, French, German, Chinese, Russian  
**Version:** 1.2.0

#### 🚀 New in This Version
- Full **Signa and Token** send/receive support  
- **Automatic Logout / Inactivity Protection** — the wallet locks automatically after idle time for enhanced safety  
- **Manage miner commitment** – add or remove your miner’s commitment easily  
- **Seven-language interface** (en, es, pt, fr, de, zh, ru)  
- **Fiat currency conversion** – view balances in multiple currencies  
- **QR code support** for importing accounts, sending payments, and creating payment requests  
- **Transaction details** with P2P message decryption  
- Enhanced **node management** – use trusted defaults or add your own  
- **PIN and biometric authentication** for fast and secure access  
- **Performance and stability** improvements  

#### 🔒 Security
- Local encryption of private keys  
- Recovery phrase is **never stored**  
- Offline transaction signing for full privacy  
- **Automatic inactivity logout** – protects your wallet if left unattended  

#### 🌍 General
- Open Source and community-driven  
- Developed for the decentralized Signum ecosystem  
- Clean, modern design with intuitive navigation  
- ⚡ **Note:** The app does *not* perform mining on your device —  
  it only manages the **commitment** associated with your existing Signum miner setup.
